Cloudflare research dispatch

The "remote worker" is a GitHub Actions job. It runs on the user's runner (their machine or GitHub's), in the user's repo. The broker on Cloudflare starts it, then the job reports back over HTTP.

One /research comment, end to end

Why the job can be trusted without a password

  • The task password stays in the Pending DO. It is never in the dispatch payload, which GitHub stores, and never on the runner.
  • The job proves who it is with a GitHub OIDC token. The Worker checks the signature, that its repository id equals the one saved at dispatch, and that its workflow is on an allowlist.
  • Each refusal is the same bare 401. The record expires after 15 minutes if the job never reports.
